Цель работы разработка своих шаблонных контейнеров на C++17: стек, очередь, двусторонняя очередь.

Особое внимание уделено управлению динамической памятью: времени жизни объектов, обработке исключений, уменьшению сложности вычислений.

Deque<T> - основа проекта. Это двусторонняя очередь на связанной последовательности блоков. Это позволяет избежать перевыделения памяти с копированием или перемещением объектов, и добавление/удаление с обоих концов сложностью O(1) (не амортизировано).

Реализовано ручное управление памятью (даже без стандартных аллокаторов). Применяются:
::operator new чтобы выделить неинициализированную память.
placement new для конструирования объектов в выделенной памяти.
~T() явный вызов деструктора для уничтожения объекта.
::operator delete для освобождения памяти

Выделение памяти и конструирование разделено. Это позволяет не создавать объекты в пустых ячейках.

Так же такая архитектура позволяет поддерживать пользовательские типы.
Реализованы emplace_back() и amplace_front(), позволяющие конструировать объекты сразу в памяти.

Поэтому тип T больше не обязан иметь: конструктор конструктор по умолчанию, конструктор копирования, конструктор перемещения, операторы присваивания.

При ошибке выделения памяти или конструирования объекта выделенная память освобождается, что позволяет избежать утечек, и структура контейнера остаётся корректной.

Стек и очередь реализованы с помощью Deque<T> по принципам LIFO, FIFO соответственно.

Изначально deque создавалась на кольцевом буфере, но это ставило ограничение необходимостью возможности копирования T + амортизированная сложность. Этот вариант остался в проекте под названием TDeque<T>
